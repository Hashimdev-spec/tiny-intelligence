# 06 · Phantom traffic jams

A Nagel-Schreckenberg traffic simulation: cars on a ring road that speed up, don't crash, and sometimes brake for no reason.

```bash
python traffic_sim.py
```

My results: 40 cars, nobody stops. 80 cars, 30.6% standing still with no accident. Remove the random braking and that drops to 1.2%. One stopped danfo jams everyone behind it.

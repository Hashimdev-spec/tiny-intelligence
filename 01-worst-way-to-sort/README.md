# 01 · The worst way to sort numbers

Python's built-in sort vs bubble sort vs bogosort vs "delete sort" (delete anything out of order 💀).

```bash
python worst_sorts.py
```

My results: Python sorted 1,000,000 numbers in 0.22s. Bubble sort took 2.7s for 10,000 numbers (≈7.5 hours for a million). Bogosort needed 2,255,974 shuffles for 10 numbers. Delete sort turned 1,000,000 numbers into a perfectly sorted list of… 11.
